SEU SUPERCOMPUTING

本地终端，远端算力。

SEU SC Bridge 将 SEU 超算 WebShell 转换为本机 SSH 入口。Go 协议核心配合系统凭据存储，无需 WSL 或 Python。

支持
交互式 Shell · 命令执行 · 多会话 · PTY 缩放
平台
Windows 10/11 · macOS Intel / Apple Silicon
当前范围
WebShell PTY 桥接。支持 SFTP 与现代 scp 上传下载；暂不支持端口转发和 VS Code Remote。
