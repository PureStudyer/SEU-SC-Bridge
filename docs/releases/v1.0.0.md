# SEU SC Bridge v1.0.0 · Public Preview

登录 SEU 超算一次，即可在本地终端运行 **ssh seusc**。无需 WSL、Python 或手动复制 Token。

这是首个公开预览版。Windows x64 已完成真实账号端到端验证；Windows ARM64 已构建但未实机验证，macOS 尚待实机验收。

## 下载

- **SEU-SC-Bridge-Setup-x64.exe**：Windows 10/11，Intel / AMD 电脑。
- **SEU-SC-Bridge-Setup-arm64.exe**：Windows 11 ARM64 电脑。
- **SHA256SUMS.txt**：下载文件校验值。
- **SEU-SC-Bridge-amd64.dmg / SEU-SC-Bridge-arm64.dmg**：macOS Intel / Apple Silicon 实验包，CI 构建通过，未实机验收、未 Developer ID 签名/公证。
- **BUILDINFO.txt**：构建源码提交及 CI 运行地址。

Windows 安装包尚未代码签名。需要 Chrome / Edge / Chromium，以及 WebView2 Runtime。安装过程使用当前用户目录，无需管理员权限。

## 开始使用

1. 安装并打开 SEUSC。
2. 输入超算平台账号和密码，点击“登录并启动”。有验证码/统一认证时按浏览器提示完成。
3. 打开终端运行 ssh seusc。

默认不记住密码；可以选择保存到系统凭据管理器。浏览器会话会持久化到独立 profile。关闭窗口后代理继续运行。

## 本版内容

- 自动登录、令牌获取和代理重启后的会话恢复。
- SSH 交互终端、多会话、中文、控制字符和窗口缩放。
- ssh seusc hostname / pwd / squeue 与远端退出码。
- 自动生成 SSH 密钥、Host 别名和专用 known_hosts。
- 原生后台、Wails 界面、系统托盘、自启动、日志与 doctor。

## 已知限制

- 这是 PTY 桥接，尚不支持 旧版 SCP（scp -O）、VS Code Remote SSH 或端口转发。
- exec 不支持 stdin 管道，stdout/stderr 合流，可能带 CRLF，命令长度约限 3 KB。
- 当前平台采用 JSON 输入，任意非 UTF-8 输入需使用旧版 binary 协议；终端输出保持原样。
- 上游断线会关闭当前 SSH 会话。
- ARM64 实机、macOS GUI/Keychain/LaunchAgent、完整终端应用矩阵和电脑重启场景仍需验收。
- 本次没有经过 Developer ID 签名/公证的 macOS 包，也没有 Windows 代码签名。

完整说明见仓库 README；问题反馈请脱敏，勿上传密码、Token、Cookie 或私钥。

## SFTP / scp 文件传输

支持标准 SFTP 与现代 OpenSSH scp，通过 SEU Finder 接口上传和下载。已实测 1 MB 随机二进制 scp 往返，以及超过 10 MB 的分块文件、空文件、中文空格文件名的 SFTP 往返，SHA-256 一致。支持目录查询、创建、重命名、删除；rmdir 使用非递归空目录删除。暂不支持追加、权限/时间戳保留（scp -p）、链接创建及旧 scp -O 协议。本机需要文件暂存空间，具体命令与限制见 README。
